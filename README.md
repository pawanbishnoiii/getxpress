# GetXpress

GetXpress is a courier and parcel delivery platform built with React, TanStack
Start, and Supabase.

## Development

Requires Node.js and npm.

```sh
npm ci
npm run dev
```

Useful checks:

```sh
npm run lint
npm test
npm run build
```

Configure the required Supabase, maps, and provider credentials in your local
environment or deployment platform. Never commit `.env` files, API keys, or
other secrets.
