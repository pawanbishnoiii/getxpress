# Indian postal reference data

- Postal office names, PIN codes and district metadata: https://github.com/avinashcelestine/Pincodes-data (`postofficeswithpins.csv`).
- Additional PIN/city/state coverage: existing `public/data/india-pincodes.csv` supplied with the copied project.
- State and district names: https://github.com/CodingMation/indian-states-districts.

Imported on 2026-10-22. These community datasets are not a live courier coverage promise and can contain historical district names. Users can enter a current district manually. Refresh against the Government of India Local Government Directory (https://lgdirectory.gov.in/downloadDirectory.do) when an authoritative export is available.
